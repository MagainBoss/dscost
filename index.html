DeepSeek API 涨价花费对比

上传 DeepSeek 开放平台导出的用量数据 zip，按 2026-08-17 生效的新版峰谷定价， 估算同样的用量在涨价前后的花费差异。所有计算均在浏览器本地完成，数据不会被上传。

将 usage_data_*.zip 拖到这里，或点击选择文件 支持 zip 或解压后的 amount-*.csv / cost-*.csv，可多选、可多次追加 · 导出路径：platform.deepseek.com → 用量信息 → 导出

    新定价分高峰（北京时间 9:00–12:00、14:00–18:00，共 7 小时）与空闲两档，空闲价为高峰的一半。 导出数据按天聚合，无法还原用量在两个时段的真实分布 —— 请按你的使用习惯拖动调整； 29.2% 对应按时长均匀分布（7÷24）的假设。

      未内置价格的模型：涨价前花费会回退使用导出明细中的单价；新价（高峰、空闲）需在此填写后才会计入估算。

      计算口径

      • 新价格于北京时间 2026-08-17 00:00 生效；高峰时段为每日 9:00–12:00、14:00–18:00， 其余为空闲时段，空闲价为高峰价的一半（来源：DeepSeek 官方定价页，2026-08-14 存档）。
      • 涨价前花费 = 各计费项 tokens × 现行牌价（未内置牌价的模型回退用明细中的单价），并与导出的账单（cost 文件）对账。
      • 涨价后预估 = tokens × [ 高峰占比 × 高峰价 + (1 − 高峰占比) × 空闲价 ]；区间下限、上限分别按全部空闲、全部高峰计算。
      • request_count（请求数）不参与计费；赠送余额、折扣活动不在本工具考虑范围内。
      • 重复上传相同时间段的数据会自动去重；上传多个 zip 可合并不同时间段。
      价格来源：DeepSeek API 文档 · 模型 & 价格（2026-08-14）。 本页面为纯前端工具，可离线使用。
